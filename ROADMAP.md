# План развития

## Сделано в 3.0 (этот выпуск)
- Новое ядро на Rust с полным набором тестов; приложение на Tauri без HTTP-сервера.
- Все критические ошибки 2.3 исправлены (см. README).
- Обработка таймлапса: удаление мерцания, стабилизация, плавное ускорение, HDR → SDR.
- Редактор: порядок клипов перетаскиванием, обрезка на шкале, кадр оформления, пробный ролик.
- Проекты, автосохранение, отмена/повтор, горячие клавиши, уведомления, прогресс в панели задач.
- CI: тесты на Linux и Windows, сборка установщиков NSIS/MSI, выпуск релизов, подпись (при наличии секретов).

## Следующий этап (3.1)
- Папка-наблюдатель: новые клипы → автоматическая сборка по шаблону проекта.
- Очередь сборок («ночная очередь» нескольких проектов).
- Автообновление (tauri-plugin-updater + подпись обновлений).
- Звук самого клипа (микширование с музыкой).
- Встроенный шрифт (OFL) и выбор шрифта из системных, текст с эмодзи через рендер в PNG.
- Английский интерфейс.

## Этап 3.2
- Импорт таймлапсов с принтеров: Bambu Lab, OctoPrint/Octolapse, Klipper (Moonraker).
- Автоудаление «пустых» участков (нет движения).
- Умное кадрирование под вертикаль (слежение за объектом).
- Публикация: Telegram Bot API, затем YouTube и TikTok.
- Шаблоны оформления (набор фирменного стиля).
