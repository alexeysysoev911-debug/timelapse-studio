# Timelapse Studio 3

Настольная программа для Windows: собирает из таймлапс-клипов готовые ролики для TikTok, Reels, Shorts и Telegram.

Что умеет:
- музыка, переходы в такт и текст;
- стабилизация и удаление мерцания;
- обложки и описания с хэштегами.

Вся обработка идёт локально.

## Что нового по сравнению с 2.3

| Было (2.3) | Стало (3.0) |
|---|---|
| Python + Flask, интерфейс через локальный HTTP-сервер (уязвим для запросов с веб-страниц) | Rust + Tauri, **нет HTTP-сервера**, интерфейс общается с ядром через IPC |
| Клипы разного разрешения ломали сборку | Каждый клип приводится к кадру до склейки |
| Ошибка в параллельной сборке → исходники уходили в архив/удалялись | Исходники трогаются, только если **все** форматы собрались; удаление — в Корзину |
| NVENC проверялся на кадре 64×64 → видеокарта NVIDIA не использовалась | Проверка на 256×256 |
| Звук 96 кГц, нет цветовых меток | 48 кГц, BT.709 |
| Запятые и `%` в тексте искажались | Текст передаётся файлом, без экранирования |
| Полоса прогресса была статичной | Анимируется (проверено тестом по пикселям) |
| Второй запуск запускал вторую копию | Один экземпляр, второй запуск выводит окно на передний план |
| Сон компьютера / свёрнутое окно убивали рендер | Сборка не зависит от окна, сон блокируется на время сборки |
| Недописанные файлы при сбое | Запись в `.part`, переименование только после успеха |
| — | Стабилизация, удаление мерцания, плавное ускорение, HDR → SDR, 8 переходов, HEVC, 24–60 fps, 4:5 |
| — | Редактор: порядок перетаскиванием, обрезка на шкале, кадр оформления, пробный ролик |
| — | Проекты `.tlsproj`, автосохранение, отмена/повтор (Ctrl+Z/Y), горячие клавиши |
| — | Прогресс на значке панели задач, уведомление Windows о готовности |

## Структура

```
crates/tls-core/     ядро (Rust): модель проекта, анализ файлов, граф ffmpeg, рендер, бит-синхронизация
  src/graph.rs       построение команды ffmpeg — чистая функция, покрыта модульными тестами
  src/pipeline.rs    сборка целиком: проверка → музыка → стабилизация → форматы → обложки → исходники
  tests/render.rs    интеграционные тесты на настоящем ffmpeg (набор «неудобных» файлов)
src-tauri/           оболочка приложения: команды, фоновая сборка, системная интеграция
ui/                  интерфейс (React + TypeScript), ui/src/logic.ts покрыт тестами (vitest)
.github/workflows/   CI: тесты на Linux и Windows, сборка установщика, выпуск версий
scripts/             загрузка ffmpeg для упаковки
```

## Сборка на своём компьютере (Windows 10/11)

1. Установите [Rust](https://rustup.rs) (stable, MSVC) и [Node.js 22](https://nodejs.org). Visual Studio Build Tools с компонентом «Разработка классических приложений на C++» ставится вместе с Rust.
2. Положите `ffmpeg.exe` и `ffprobe.exe` в `src-tauri\resources\ffmpeg\`. Подойдут те, что у вас уже есть, или выполните `pwsh scripts\fetch-ffmpeg.ps1`.
3. Выполните:

```bat
cd ui
npm ci
cd ..\src-tauri
node ..\ui\node_modules\@tauri-apps\cli\tauri.js dev     :: запуск в режиме разработки
node ..\ui\node_modules\@tauri-apps\cli\tauri.js build   :: установщики в target\release\bundle\
```

Установщик NSIS ставит программу для текущего пользователя без прав администратора. Если в системе нет WebView2, он доустанавливает его сам.

## Тесты

```bat
cargo test -p tls-core      :: ядро: модульные и интеграционные тесты (нужен ffmpeg в PATH)
cd ui && npm test           :: логика интерфейса
```

Интеграционные тесты генерируют «неудобные» файлы и проверяют результат через ffprobe:
- 1080p и вертикальное видео, переменная частота кадров, HDR HLG 10 бит;
- кириллица и запятые в имени, битые файлы с «правильным» расширением;
- 90-секундный исходник.

Проверяются разрешение, длительность, частота звука, цветовые метки, кодек, анимация полосы прогресса, отмена, сохранность исходников при ошибке, все переходы и режимы кадрирования.

## Выпуск версии

1. Поднимите версию в `Cargo.toml` (`workspace.package.version`), `src-tauri/tauri.conf.json` и `ui/package.json`.
2. `git tag v3.0.1 && git push --tags`. Workflow **Release** соберёт и протестирует установщики и создаст черновик релиза на GitHub.

### Подпись (убирает «Windows защитил ваш компьютер»)

Нужен аккаунт [Azure Trusted Signing](https://learn.microsoft.com/azure/trusted-signing/) (около $10 в месяц). Добавьте в секреты репозитория:

- `AZURE_TENANT_ID`, `AZURE_CLIENT_ID`, `AZURE_CLIENT_SECRET`;
- `AZURE_SIGNING_ENDPOINT`, `AZURE_SIGNING_ACCOUNT`, `AZURE_CERT_PROFILE`.

После этого релизы подписываются автоматически, включая exe внутри установщика.

|---|---|

## Лицензии

Код программы распространяется по лицензии MIT. ffmpeg — отдельная программа под GPL v3, подробности в `LICENSES/README.txt`.

Встроенные треки из версии 2.3 намеренно не включены. Лицензии бесплатной музыки обычно запрещают распространять файлы отдельно от видео. Пользователь добавляет свою музыку сам.
