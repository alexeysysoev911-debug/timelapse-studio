1. Загрузить установщик

Перетащите сюда оба файла из сборки GitHub: …x64-setup.exe и …x64-setup.exe.sig (подпись — без неё программы не примут обновление).

2. Выпустить версию

Сейчас на сервере: —. После выпуска программы у пользователей предложат обновиться, а сайт покажет новую версию.

Пользователь увидит предложение обновиться и сам решит когда.

Можно не скачивать файлы вручную: добавьте в GitHub секреты TLS_SERVER_URL и TLS_DEPLOY_KEY (вкладка «Настройки») — сборка «Release» сама положит установщик и подпись сюда, останется нажать «Выпустить».
Можно: только текст, только картинку или всё вместе. Пустой или выключенный блок не показывается. В программе изменения появятся при следующем запуске, на сайте — сразу.
