# Сайт и сервер Timelapse Studio

Рекламный сайт программы, панель управления в браузере, обновления, 2 рекламных блока в программе и 2 на сайте, статистика.
Один файл на Python (без установки библиотек) за nginx. PhotoMetaName на том же VPS не затрагивается.

| Адрес | Что это |
|---|---|
| `https://tls.shadowpathlink.org` | сайт программы |
| `…/admin` | панель управления (вход по паролю) |
| `…/updates/latest.json` | откуда программа узнаёт об обновлениях |
| `…/downloads/latest` | ссылка «скачать последнюю версию» |

## Установка (один раз)

1. **DNS:** добавьте A-запись `tls` → IP вашего VPS (того же, где `pmn`).
2. Скопируйте на VPS **всю папку** из архива `timelapse-server` (в ней `server.py`, `install.sh`, `admin/`, `site/`) и выполните в ней:
   ```bash
   sudo bash install.sh tls.shadowpathlink.org
   ```
   Скрипт спросит пароль панели (от 10 символов), поставит службу, сайт nginx с защитой от перебора и флуда
   и бесплатный HTTPS-сертификат. В конце покажет **ключ для GitHub** (`TLS_DEPLOY_KEY`).
3. **GitHub** → Settings → Secrets and variables → Actions:
   - `TLS_SERVER_URL` = `https://tls.shadowpathlink.org`
   - `TLS_DEPLOY_KEY` = ключ из шага 2

Обновить сайт или сервер позже — снова `sudo bash install.sh tls.shadowpathlink.org` из новой папки
(данные, пароль, статистика и сертификат сохраняются).

## Выпуск новой версии программы

1. Поднимите номер версии **одинаково** в `src-tauri/tauri.conf.json`, `ui/package.json` и `Cargo.toml` (например 3.0.1).
2. GitHub → Actions → **Release** → Run workflow.
3. Сборка сама загрузит установщик и подпись в панель. Сервер **проверяет цифровую подпись** —
   чужой или повреждённый файл выпустить нельзя.
4. Панель → «Обновление» → «Выпустить версию». Тип: обычное / крупное / **обязательное**
   (блокирует старые версии до обновления; если обновление не встанет, пользователь сможет скачать его с сайта).

## Безопасность

- Панель: пароль хранится как PBKDF2-хэш, сессия — cookie `HttpOnly; Secure; SameSite=Strict`,
  защита от подделки запросов, ограничение попыток входа (nginx + сервер), смена пароля завершает все сессии.
- Сайт и панель: строгий Content-Security-Policy без встроенных скриптов, HSTS, запрет встраивания в чужие сайты.
- Загрузки: проверка размера и сигнатуры файлов, подпись обновлений проверяется по ключу программы.
- Служба работает от отдельного пользователя без права входа, с изоляцией systemd; писать может только в `data/`.
- IP-адреса на диск не пишутся: посещения считаются по хэшу с ежедневно меняющимся ключом.

## Полезное

- Журнал: `journalctl -u timelapse-server -f`
- Перезапуск: `sudo systemctl restart timelapse-server`
- Сменить пароль из консоли: `sudo -u tls env TLS_DATA=/opt/timelapse-server/data python3 /opt/timelapse-server/server.py password`
- Ключ для GitHub: `sudo -u tls env TLS_DATA=/opt/timelapse-server/data python3 /opt/timelapse-server/server.py deploy-key`
- Резервная копия: папка `/opt/timelapse-server/data` (версии, реклама, статистика, настройки).
